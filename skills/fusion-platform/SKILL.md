# 融合平台（广州交通"一张图"）知识库

本 skill 是广州交通运输局融合平台的权威内容来源，正文逐字保留自官方《系统演示脚本》，存放在 `references/`。回答平台相关问题时**以 references 中的原文为准**。

## 平台是什么

融合平台整合 **20 多个业务系统数据**，融合分析各类交通数据资源，梳理关键指标，打造广州市交通运输局数据"**一张图**"，全面覆盖 **综合交通、道路运输、城市交通、基础设施、交通执法、电子政务** 六大主题板块。

平台首页呈现"广州大交通"，从六大板块中选取宏观的、主要的指标展示行业规模与运营情况。中间地图依托**全息投影概念**，通过底部沙盘投射出**七个交通管理场景**。

## 页面术语（脚本中的固定说法）

- **一级页面 / 二级页面**：板块首页 / 下钻的行业页。首页讲宏观，二级页面"地图内容也更丰富"。
- **图层**：叠在地图上的主题数据层（如公交图层、BRT图层）。城市交通首页按左右七个模块的划分逻辑"共设计了七个图层"。
- **打点**：在地图上按点位标识对象（站点、企业、监测点、卡口等）。
- **聚合打点**：点位密集时合并显示数量。
- **热力图**：表达密度/分布强度（如巡游车上下车位置、共享单车出行点）。
- **场景**：独立于页面的专题分析入口（两客一危一重、节假日交通）。
- **BIM 模型**：用于广州南站、白云机场的运力与车辆调度监测。

- **得分率** — 单项得分占该项总分的比值，用于分析共享单车企业在各方面的工作水平（下文未写成"得分率"但同义）。

- **行讯通、公交社区** — 面向市民打造的便民服务。
